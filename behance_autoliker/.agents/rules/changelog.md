# Правило: обновление CHANGELOG.md

После **каждого изменения кода** в этом проекте ты ОБЯЗАН добавить запись в
[`CHANGELOG.md`](file:///c:/Projects/Business/Web_projects_NEW/behance_autoliker/CHANGELOG.md).

## Формат записи

```
## [YYYY-MM-DD HH:MM] — <Краткое название изменения>

**Причина:**
<Почему это было сделано: баг, поведение, которое сломалось, или новая потребность>

**Изменено:** `<файл.py>` [→ функция/класс, если уместно]
- <Что конкретно добавлено/удалено/изменено — bullet-листом>

**Результат:**
<Что теперь работает иначе. Конкретно и измеримо.>

---
```

## Правила вставки

- Новая запись всегда идёт **сразу после строки `---` в начале журнала** (свежее — сверху).
- Время — местное время пользователя на момент изменения.
- Не пропускай запись даже для «мелкого» фикса: однострочные правки тоже документируются.
- Если в одном ответе изменено несколько файлов — одна запись суммирует всё.
