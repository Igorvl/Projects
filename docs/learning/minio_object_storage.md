# 📦 MinIO — Объектное Хранилище (Object Storage)

## Что такое MinIO?
MinIO — это **локальный клон Amazon S3**. Это хранилище для файлов (картинок, аудио, PDF, логов) — по сути "сетевая файловая шара", но с API.

## Зачем нужно объектное хранилище, если есть диск?
Представьте, что у вас 10 000 изображений от AI-генератора. Можно хранить их просто в папке `/images/` на сервере. Но тогда:
- ❌ Нет версионирования (перезаписал — потерял оригинал)
- ❌ Нет метаданных (кто загрузил? когда? к какому проекту относится?)
- ❌ Нет HTTP-доступа (чтобы отдать картинку в браузер, нужен отдельный nginx)
- ❌ Нет масштабирования (переносить папку на другой сервер — ад)

MinIO решает все эти проблемы:
- ✅ Каждый файл доступен по прямой HTTP-ссылке
- ✅ К каждому файлу можно прикрепить метаданные (JSON-теги)
- ✅ Есть бакеты (Buckets) — как папки верхнего уровня
- ✅ S3-совместимый API — любая библиотека для Amazon S3 работает с MinIO
- ✅ Встроенная Web UI панель для просмотра файлов

## Ключевые понятия:
- **Bucket (Бакет/Ведро):** Контейнер верхнего уровня для файлов. Аналог "корневой папки". Например: `project-images`, `audiobooks`, `backups`.
- **Object (Объект):** Любой файл внутри бакета. У объекта есть ключ (путь), данные (содержимое файла) и метаданные. Ключ может включать псевдо-подпапки: `test-project/gen-001/image.png`.
- **Presigned URL:** Временная ссылка на файл, которая истекает через заданное время. Позволяет дать доступ к приватному файлу без раскрытия пароля от хранилища.

## Порты MinIO:
- **9000** — S3 API (программы ходят сюда для загрузки/скачивания файлов)
- **9001** — Web Console (браузерная панель администрирования, как phpMyAdmin для файлов)
